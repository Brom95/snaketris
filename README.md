# snaketris

A single-file HTML5 game — a **Snake × Tetris hybrid**. Pilot a snake that eats falling Tetromino pieces before they land. Once a piece touches the bottom or rests on top of another piece, it stops being edible and becomes a solid obstacle.

Play it live on GitHub Pages: **https://Brom95.github.io/snaketris/**

## How to play

- **Eat to grow:** your snake eats cells of the falling pieces, one by one. Each cell is worth **+1 score**.
- **Steer:** move with the arrow keys or **WASD**. You cannot reverse into the segment directly behind you.
- **Pieces:** the seven classic Tetrominoes — `I`, `O`, `T`, `S`, `Z`, `L`, `J` — spawn at the top and fall continuously. They are **edible while falling**.
- **Landing:** when a piece hits the bottom or lands on top of other pieces, it freezes into **solid blocks** and becomes a wall.
- **Difficulty ramps up:** the fall speed increases by a small factor every **2 landed blocks**.
- **Wrap-around:** the board wraps at all four edges — there are no walls on the sides.
- **Game over** happens when your snake's head:
  - runs into one of its own body segments, **or**
  - runs into a solid block.
- **Restart:** press **R** or click the board to start over from scratch (the score resets to 0).

## Controls

| Key | Action |
| --- | --- |
| Arrow keys / `W A S D` | Steer the snake |
| `R` / click | Start the game or restart after game over |

## How to run

There is no build step and no dependencies. Just open `snaketris.html` in any modern browser.

## Stack

- Vanilla JavaScript only
- `<canvas>` + `requestAnimationFrame` rendering
- Fixed-timestep game loop (the game pauses cleanly when the tab is hidden)
- No framework, no backend, no build step
