# Proposal

## Why

Игроки и разработчики могут сразу перейти к исходному коду проекта из главного меню, не открывая браузер отдельно. Ссылка на GitHub-репозиторий — стандартная практика для open-source игр.

## What Changes

- Добавить иконку/текстовую ссылку «GitHub» внизу главного меню (под пунктами «Play», «Records», «How to Play»), не как четвёртый пункт навигации, а как дополнительный элемент.
- При нажатии на значёк/ссылку открывается страница репозитория `https://github.com/Brom95/snaketris` в новой вкладке браузера.
- Поддержка pointer (click/tap) и геймпада; клавиатура не затрагивается (не пункт меню).

## Capabilities

### Modified Capabilities
- `start-menu`: добавление GitHub-ссылки/иконки под основными пунктами меню с действием открытия репозитория.

## Impact

- `js/constants.js` — новая константа `GITHUB_URL`, возможно новые layout-константы для позиции иконки.
- `js/render.js` — `drawMenu()` рисует GitHub-элемент под пунктами меню.
- `js/input.js` — pointer hit-test на область GitHub-ссылки; геймпад (B/edge) не затрагивает ссылку.
